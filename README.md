# Project Management System

## Overview

The Project Management System is a responsive web application developed to simplify project and task organization. It provides an intuitive interface for managing projects, monitoring progress, and improving productivity. The application is designed with a clean user experience and a responsive layout to ensure accessibility across different screen sizes.

## Features

* Responsive and user-friendly interface
* Dashboard for project overview
* Create, edit, and delete projects
* Task management within projects
* Project progress tracking
* Search and filter functionality
* Modern and clean UI
* Mobile-friendly design

## Technologies Used

* React.js
* JavaScript (ES6+)
* Tailwind CSS
* React Router
* Axios

## Installation

Clone the repository:

git clone https://github.com/your-username/project-management-system.git

Navigate to the project directory:

cd project-management-system

Install dependencies:

npm install

Start the development server:

npm run dev

The application will be available at:

http://localhost:5173
